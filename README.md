## 🚀 快速开始

```bash
# 克隆项目
git clone https://github.com/dirjaker/docker_learning.git
cd docker_learning

# 创建虚拟环境
conda create -n docker_learning python=3.12 -y
conda activate docker_learning

# 安装依赖
pip install -r requirements.txt

# 运行项目
python main.py
```
